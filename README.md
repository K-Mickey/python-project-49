## Description

Brain Games - is a collection of mini-games for training your brain.
Run the game and try to answer all the questions correctly.

The project was created as part of the [Hexlet](https://hexlet.io) course.

## Requirements

* UV 0.5 or higher
* Git

## Installation

Choose a place for the clone and run the following commands:

```bash
git clone https://github.com/K-Mickey/python-project-49.git
cd python-project-49
make install
make build
make package-install
```

After installation, you'll be able to launch the games from any directory on your computer.
